최종 출력 직전에 아래를 체크하고 누락 가능성이 있으면 적어라.
- 공식 회사/IR 확인 완료 여부
- 규제/거래소/공시 확인 완료 여부
- 임상등록 확인 완료 여부
- 경쟁사 공식 소스 확인 완료 여부
- direct class competitor 누락 가능성
- same-indication competitor 누락 가능성
- DED / FcRn / RA / SjD / CLE / TED / MG / CIDP / GD 각 적응증별 누락 가능성

중요:
- direct company 업데이트와 competitor 업데이트를 반드시 분리해서 보여라.
- 경쟁사 뉴스가 없더라도 Competitor Map Snapshot과 Checked Source Log는 반드시 출력하라.
- 새로운 업데이트가 없더라도 무엇을 확인했고 무엇이 없었는지 보여라.
- “중요하지 않은 경쟁사 잡음”보다 “중요 이벤트 누락 방지”를 우선하라.
- fact only. 숫자와 날짜가 우선이다.
