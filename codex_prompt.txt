 작업 디렉 아래 조건에 맞는 Python FastAPI 프로젝트를 생성해라.

[목표]
 R이 설치된 스마트폰과 연동할 FastAPI 서버를 만들고 있다.
  카카오톡 방별 설정(config-driven) 동작하 기반으로 취미용 MVP 백엔드다.
과하게 복잡한 구조는 원하지 않는다.
 단순한 구조로 시작하고, 나중에 확장할 수 있게만 만들어라.

#[중요한 API 
codex cli 조건]
R에서 FastAPI 서버에 접근할 기본 API 주소는 아래와 같다.

http://192.168.0.10:8000/kakao

, FastAPI 앱은 /kakao prefix 기준으로 엔드포인트를 제공해야 한다.
:
- GET /kakao/health
- POST /kakao/events/message
- POST /kakao/outbox/pull
- POST /kakao/outbox/ack

bot.js와 poller.js에서 사용할 기본 서버 주소도 위 값을 기준으로 작성해라.
 하 말고, 추후 변경 가능하도록 설정값으로 분리하기 쉽게 작성해라.

[프로젝        기능 범위]
 서버는 아래 기능을 위한 MVP 백엔드다.

1. 방별 설정 기반 동작
- room_name만 믿지 말고 channel_id 기반 식별 가능하도록 설계
- 내부 room_key를 사용
- rooms.yaml에서 방별 기능 on/off 설정

2. 메시지 이벤트 처리
- MessengerBotR가 서버로 메시지 이벤트를 POST한다고 가정
- endpoint: POST /kakao/events/message
- 요청에는 최소한 아래  포함된다 가정
  - room_name
  - channel_id
  - sender
  - message
  - log_id
  - package_name
  - received_at
- 응답은  포맷으로 반환
  - ok
  - trace_id
  - action
  - messages
  - error
  - meta

3. 유튜브 URL 처리
- message에서 YouTube URL 추출
- youtu.be, youtube.com/watch, shorts 형태 기본 지원
- video_id 정규화
- 같은 room_key에서 같은 video_id를 일정 시간 내 중복 처리하지 않도록 SQLite에 기록
- 실제 요약은 우선 placeholder 함수로 구현해도 됨
- 다만 함수 구조는 나중에 실제 LLM/API 연결이 쉽게 되게 작성
- 응답은 한국어 텍스트로 반환

4. 스케줄 
- APScheduler 사용
- scheduler.py에서 job 등록
- 매일 오전 7 family_room에 날씨 + 아들 개월 수 메시지 생성
- 매일 오전 7시 stock_news_room에 뉴스 요약 메시지 생성
- prompts.yaml 기반 TEST 프롬프트 실행 샘 job 1개 포함
- 스케줄 작업 결과는 즉시 전송하지 않고 SQLite outbox 테이블에 저장

5. Outbox
- MessengerBotR가 가져갈 수 있도록
  - POST /kakao/outbox/pull
  - POST /kakao/outbox/ack
  엔드포인트 구현
- pending  outbox에서 조회
- ack 성공 시 sent 처리
- 실패 시 retry_count 증가 가능하게 설계

6. 날씨 / 뉴스 / 개월 수
- weather, news는 실제 외부 API 대신 우선 mock/placeholder 함수 가능
- 하지만 나중에  분리
- child age는 .env의 SON_BIRTH_DATE를 기준으로 계산
- 출력은 “오늘 기준 N개월” 형태
- 옵션으로 일수 포함 가능하도록 함수 인자 고려

7. DB
- db.py에서 SQLite 초기화
- 최소 테이블:
  - processed_messages
  - processed_videos
  - outbox_messages
  - job_runs
- 필요하면 rooms 캐시/매핑 없이 YAML만 사용해도 됨
- 앱 시작 시 자동 테이블 생성

[main.py 요구사항]
- FastAPI 앱 생성
- /kakao prefix를 적용하라
- startup 시 DB init + config load + scheduler start
- shutdown 시 scheduler stop
- 위 엔드포인트 연결
- 예외 처리 기본 구현
- JSON UTF-8 응답 안정성 고려

[config.py 요구사항]
- .env 로드
- rooms.yaml 
- prompts.yaml 로드
- 설정 접근 헬퍼 제공
- timezone 문자열 관리
- API base path는 /kakao 기준으로 다룰 수 있게 하라

[db.py 요구사항]
- sqlite3 연결
- init_db()
- dedupe 조회/저장 함수
- outbox enqueue / pull / ack 함수
- job run 기록 함수

[scheduler.py 요구사항]
- APScheduler 설정
- register_jobs()
- family morning brief job
- stock news brief job
- test prompt job
- jobs는 services.py 함수 호출 후 outbox 저장

[services.py 요구사항]
 함수들을 하나의 파일 안에 구현해라.
- handle_message_event(...)
- detect_message_features(...)
- summarize_youtube_url(...)
- run_prompt_by_key(...)
- build_family_morning_brief(...)
- build_stock_news_brief(...)
- get_weather_summary(...)
- get_news_summary(...)
- calculate_child_age_text(...)
- build_standard_response(...)
- split_long_message(...)

[utils.py 요구사항]
- extract_youtube_urls(text)
- normalize_youtube_url(url)
- extract_video_id(url)
- make_trace_id()
- now_kst()
- safe_truncate(text, limit)

 방에는 최소한:

[prompts.yaml 샘플 요구사항]

[중요]
- 먼저 전체 파일을 생성하라.
- 그 다음 각 파일의 내용을 모두 채워라.
- 모든 API 경로는 반드시 /kakao prefix 기준으로 맞춰라.
- 마지막에 내가 바로 실행할 수 있게 실행 방법을 main.py 상단 주석에 짧게 정리해라.
- 답변은 설명 위주가 아니라 실제 파일 생성/수정 작업 위주로 진행해라.
